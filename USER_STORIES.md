# Oncepass — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Customer

- As a customer, I want to approve a time-boxed KYC evidence share to a new bank, so that I am not re-uploading my passport for every product.
- As a customer, I want to revoke a grant instantly, so that consent withdrawal is real.
- As a customer, I want a list of who can currently request my evidence, so that I retain self-sovereign control.

### Home bank KYC team

- As a KYC analyst, I want to issue evidence references without placing documents on a shared chain, so that erasure remains possible.
- As a KYC lead, I want relying parties to pull only what consent allows, so that oversharing is blocked.

### Relying institution

- As an onboarding officer, I want verified evidence under customer consent within minutes, so that second-institution onboarding is faster.
- As an MLRO delegate, I want to record our own AML decision against the evidence, so that we do not outsource regulated judgment to the network.

### DPO / auditor

- As a DPO, I want consent and access logs exportable, so that accountability is demonstrable.
- As an auditor, I want proof that PD was never on-chain, so that immutability does not conflict with erasure.
- As a DPO, I want clarity on consortium controllership, so that Article 26/28 roles are not ambiguous.

### Network operator

- As a network operator, I want to suspend a relying party with anomalous access patterns, so that breaches are contained.
- As a network operator, I want SSI and permissioned modes to enforce the same PD ban, so that public-network experiments stay safe.
